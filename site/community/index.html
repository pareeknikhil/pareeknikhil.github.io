House rules

  1. 01

    Search first

    Docs, then Reference, then the journal. Repeat the four session calls if you write to someone.

  2. 02

    Show a log

    Device id, preset, and the block shape you got. A paste beats a screenshot of code.

  3. 03

    Stay kind

    Correct the map, not the person. No vendor fights. See About Us for people and license.

Questions we already answered

Where do I post a question?

You do not post it here. This page does not store threads. Use Ask Help for contact, or read Docs and Reference first.

Is there a chat or member list?

No. Ability’s public face is this static site. No accounts, no comments, no database. The “room” is the shared API and the notes in the journal.

How do I report a bug?

Include device id, preset, language binding, and the four session calls. Send that through Ask Help so it arrives as mail, not as a row in a table we do not run.

Can I contribute a page?

Yes, as a file. Follow the Docs/Reference heading pattern, keep Ability copy (not another library’s), and send it the same way you would a bug note.
