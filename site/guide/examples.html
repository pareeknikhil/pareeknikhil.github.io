Docs/Code Samples

Code Samples

Confirm Ability is installed, then run a short session: prepare, start, read, stop. Samples below use the same flow in each language.

Python

To run some of the samples below you may also want matplotlib and pandas.

Python Get Data from a Board

Python Get Data from a Board uses the same Ability session flow: construct with a device id, prepare, start, read a block, then stop. Lorem ipsum dolor sit amet, consectetur adipiscing elit.

import time
import ability as ab

def main():
    session = ab.Session(device_id=0)
    session.prepare()
    session.start()
    time.sleep(8)
    data = session.read()
    session.stop()
    print(data.shape)

if __name__ == "__main__":
    main()
